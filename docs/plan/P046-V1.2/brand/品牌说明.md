# P046 品牌资产说明（云端已选定）
- 正式中文显示名称：**麻将小白助手**；英文显示名称：**Mahjong Quick Guide**；项目编号 P046 保持不变。
- 标语：**各地玩法，一看就懂。**（英文：Local Rules, Made Simple.）
- 品牌图形：翡翠绿底 + 象牙白麻将牌 + 绿色「胡」字 + 金色提示光芒。参照 AI 品牌概念图，同时提供可复用的生产版扁平资源。
- 主题：主要品牌绿 `#087454`；Light 背景 `#F3F8F4`，Dark 背景 `#10211C`；文本与 UI Token 以已通过的 C 原型语义为准。
- 应用商店主图：`icons/play-store-512.png` 512x512 正方 PNG，仅作首版品牌稿；发布前检查应用商店图标政策、商标/名称重名及真机清晰度。
- Android Adaptive Icon：`android/res/mipmap-anydpi-v26/ic_launcher.xml`，对应独立背景与透明前景 / monochrome；确保 Android 所需 108dp 与内圈 66dp 安全区。
- Android Splash：采用**系统 SplashScreen API**，Light/Dark 两个纯色背景 + 中央 logo，尽快进入首页；不得额外设计强制停留的欢迎页。`splash-preview-*.png` 是仅用于审美预览的静态样张，不是 Android 系统实际截屏。
- `android/res/values*/p046_brand_colors.xml` 可用于启动主题；由 Android Builder 合并入本项目当前 manifest/theme，不能直接覆盖现有主题文件。
- 业务多语言：zh-CN + en，FOLLOW_SYSTEM 默认；资源要与业务数据/术语释义分离；系统不支持语言回退简体中文。
- MagicPath 旧稿上的「麻将一看懂」仅为临时头部文案；正式原型应替换为「麻将小白助手」。
- 命名是本轮云端推荐定版输入，**不是法定商标检索通过或 Android QA 通过**。
- Android 原文：https://developer.android.com/develop/ui/compose/system/icon_design_adaptive 与 https://developer.android.com/develop/ui/views/launch/splash-screen

- **原生 Android 优先资源**：`android/res/drawable/p046_adaptive_fg.xml`（矢量前景，含胡字的 SVG path 转换，自带字形轮廓，不依赖手机安装汉字字体）、`p046_adaptive_mono.xml`、`p046_splash_icon.xml`。Bitmap PNG 同时提供，供视觉对照与非原生渠道使用。`ic_launcher.xml` 当前引用这些原生 VectorDrawable。
- Android Theme 启动配置由 ORCA Builder 合入正式工程：SplashScreen 背景 `@color/p046_splash_background`，中心图标 `@drawable/p046_splash_icon`，postSplashScreenTheme 复用项目正式 App 主题。
