## 1. S1 首页（双入口）

- **状态**：
  - 空态：不适用（静态入口，始终可用）。
  - 错误态：不适用（无网络依赖；离线仍可用）。
  - 灰色/低置信态：不适用（入口层不承载规则结论）。
- **返回行为**：首页为根，系统返回键退出应用（不返回空白页）。
- **主题/语言**：随全局设置即时渲染；中文名与英文名按语言资源切换（zh-CN 显示「麻将小白助手」，en 显示「Mahjong Quick Guide」）。

- **状态**：

## 3. S3 玩法详情（核心屏）

- **入口**：S2 选择某具名玩法。
- **元素**：
  1. 版本头：**具名玩法名＋地区**＋证据等级＋资料版号/日期；来源可点（联网时打开外部链接，离线时置灰但可读）。
  2. 规则简介（3 分钟速看入口按钮）。
  3. **对照牌面区**：真实牌面图，标注牌张分组、所缺牌/条件、是否已满 14 张。**地方流程可观察呈现（B-04）**：
     - **海南（E04~E07）**：**花牌独立于 14 张手牌之外单独成区展示**，且**座风（东/南）与眼（对子）在同一屏同时可见**；E06 东位春花算番但**眼仍是三条一对**；E07 南位春花不自动算番，且**须与「明碰 111 筒、无其他番」前提一并展示**（B-03）。
     - **四川（E08~E10）**：**E08 声明缺 S 时高亮全部条牌**（结构完整仍不满足定缺）；E09 呈现「只剩万和筒已缺条」；E10 呈现七对特殊牌型（与四组一对不同）。
     - **广东（E11/E12）**：**同一 14 张结构并列展示**「自摸→可胡」与「普通点炮→不胡」两个上下文与**不同结果**；标注这是**波克发行版本、不代表全广东**。
     - **换三张等变体项**：以「**该版本属性/开关说明**」呈现；点击若**仅展示解释**（不改变示例判定）须写清，**不得由静态示例推出未核实的新结论**（AC-26/AC-54）。
  4. 术语内嵌入口（眼/将、碰、杠、吃、花、番、缺门、自摸、点炮…）。
  5. 「对比其它版本」入口（FR-10；UF-07，非核心 P1）。
  6. 「上桌前要问的三件事」**可见并可收藏**区（R-1 桌规不可穷尽对策；AC-49）。**收藏保存结果（B-01）**：点击收藏/取消后**离开本页再返回，收藏状态仍保持为已收藏/已取消，且可再次切换**；**不得只验即时图标**。**本区只承诺「离开再返回」范围内可观察，未承诺跨重启持久化。**
- **状态**：
  - 空态：该玩法仅有简介、无对照牌例 → 显示「本版本暂无对照牌面」＋仍可读简介与来源。
  - 错误态：来源链接打不开（联网异常）→ 显示「来源暂不可访问，内容基于已归档资料」。
  - 低置信灰态：争议条款/未证实项（如「当花又当眼」、重庆变体）显示灰色说明卡「该说法/该条款暂无法核实」，**不出确定性胡牌结论**。
- **返回行为**：返回 S2；**不丢用户所在玩法与滚动位置**（AC-10）；离开本屏再返回时**「三件事」收藏状态仍保持，并可再次取消/收藏**（AC-49）。
- **主题/语言**：牌面页为专注阅读页，遵守用户所选主题（**不强制另一态**，FR-15/AC-35）。
- **返回/选择保持口径（B-04）**：从本屏进入 S4/S6/S7/S8 后返回，**保持当前玩法、滚动位置、已选示例与展开状态**（AC-10）；换三张开关等**仅改变解释展示、不改变已选静态示例的判定结论**。

- **状态**：

## 7. S7 牌例判定（「为什么不能胡」）

- **入口**：S1「问题」→「为什么不能胡」；或由 S3 对照牌面追问。**牌例只能从已审核示例列表（E01~E16）选择**，列表项＝示例标题＋一句话预览（见 §10 示例搜索契约，B-02）。
- **两级判定流程**：①**手牌结构级**（13 张等待 / 14 张不合法 / 14 张结构成立）→ ②**地域条件级**（所选具名玩法的额外闸门：定缺、自摸限制、起和分等）。**不做自动裁定引擎**，只做两级解释。
- **四态结论呈现规则（FR-04，统一口径＋逐例例外，B-03）**：
  1. **能胡（前提成立）**：绿色结论条「按〈玩法名〉前提，满足胡牌条件」＋为什么＋前提条件逐条列出。**前提必须逐例展示**（座风/花牌/缺门/七对选项/最后一张来源）。
  2. **不能胡**：红色/中性结论条「按〈玩法名〉，不能胡」＋为什么（如违背定缺、普通点炮被禁）。
  3. **未满足额外条件**：琥珀色结论条「结构成立，但还差…」＋差什么（13 张待补张 / 未过地区闸门 / 番不足）＋**明确区分 13 张与 14 张**。
  4. **依据不足**：**灰态**结论条「依据不足，需先确定具体玩法」＋说明（未证实的说法、未选版本、需计分）。
  - **逐例例外（统一短句不得覆盖，B-03；逐例确切文案以 `PRODUCT_PLAN_V1.0.md` Data/API 验收表为准）**：
    - **E01（13 张等待）**：文案为「**13 张，四组三张已齐、尚缺一张（眼）**」——**不得**对 13 张未成对说「结构成立」。
    - **E02/E16（通用结构完整）**：文案为「**通用结构已成，但不代表地方可胡**」——**不得**当成某地区可胡。
    - **E03（14 张不合法）**：文案为「**当前已是 14 张，无法另作普通四组一对**」——**绝不**说「再摸一张就胡」。
    - **E14（国标计分）**：文案为「**已选 MCR1998 国标，但仅凭牌形无法断定达 8 分起和线，需结合吃碰/门清/和牌方式计分**」——**不要求重新选玩法**，**V1 不提供算分器**，维持「依据不足」灰态（**不得**套用「需先确定具体玩法」通用句）。
    - **E15（版本未定）**：文案为「**版本未定，先选明确变体**」——走**灰态**。
  - 硬规则：通用结构**不得**等同某地区可胡；花牌**不得**当对子；有条件例**前提未知时不得转成无条件绿色结论**。
- **元素**：手牌牌面（真实 PNG）；**花牌置于手牌之外单独显示**；**结论四态条**（颜色＋文字双编码）；「为什么」；「差什么/如何补」；适用规则与来源；两级判定可展开。**地方流程呈现（B-04）**：E08 声明缺 S 时**高亮全部条牌**；E11/E12 **同一结构并列自摸/普通点炮的上下文与不同结果**。
- **状态**：
  - 空态：未选牌例 → 提示「请从上方示例列表选择一个牌例」；示例搜索无匹配 → 「未找到匹配示例」。
  - 错误态：无（本地数据）。
  - 低置信灰态：**依据不足态即灰态**（重庆泛称 E15/未证实术语/国标计分 E14）。
- **返回行为**：返回来源页；保留已选牌例与两级判定展开状态（AC-10）。
- **对应**：UF-03/UF-05/UF-06｜FR-04/FR-03/FR-07｜AC-04/AC-05/AC-06/AC-26/AC-27/AC-42/AC-43/AC-52/AC-53/AC-54。

## 9. S9 设置（主题与语言）

- **入口**：右上角 `设置`（S1 及各页可达）。
- **主题设置项**：`浅色 LIGHT` / `深色 DARK` / `跟随系统 SYSTEM`；**默认 `SYSTEM`**。
- **语言设置项**：`跟随系统 FOLLOW_SYSTEM` / `简体中文` / `English`；**默认 `FOLLOW_SYSTEM`**。
- **两个开关的触发条件分开写清（B-06，硬约束）**：
  - **`SYSTEM`（主题）只随设备「外观」**（浅/深）变化：设备切深色→APP 变深色；设备切浅色→APP 变浅色。**手动 `LIGHT`/`DARK` 不随设备外观变**（用户选项优先）。
  - **`FOLLOW_SYSTEM`（语言）只随设备「语言」**（locale）变化。**手动「简体中文/English」不随设备语言变**。
  - **两者互相独立**：改设备外观**不影响**语言选择，改设备语言**不影响**主题选择；一个手动、一个跟随可并存。
  - 系统语言不受支持时**统一回退 `zh-CN`**（不空白、不回退 en）。
- **持久化与读取边界**：主题/语言选择**重启后保留**；**持久化值在首帧（含 Splash）之前读取并生效**，避免闪错色/闪错语言。
- **冷启动一致性判据（B-06）**：
  - `LIGHT` + 设备深色 → 冷启动 Splash 用浅色底 `#F3F8F4`，首页保持 `LIGHT`（不随设备变暗）。
  - `DARK` + 设备浅色 → 冷启动 Splash 用深色底 `#10211C`，首页保持 `DARK`。
  - `SYSTEM` + 设备外观 → Splash 与首页**跟随设备外观**，Splash→首页**无闪错色**。
  - **真机验收步骤**：①三组冷启动录屏（Splash→首页）；②重启后主题/语言仍为所选；③分别改设备外观/语言，验证各自独立触发。
- **切换时状态保持**：**切换主题或语言后，返回用户所在规则页，保持同一玩法、滚动位置、已选牌例、对比选择、两级判定展开状态、搜索查询**（不重置业务状态、不清空查询）（AC-16/AC-33）。
- **元素**：主题三选（单选）；语言三选（单选）；关于/来源与「非博彩声明」入口。
- **状态**：
  - 空态/错误态：不适用（纯本地设置）。
  - 低置信灰态：不适用。
- **返回行为**：返回进入设置前的页面，状态保持。
- **对应**：UF-08｜FR-13~FR-22｜AC-11~AC-16/AC-29~AC-34/AC-41/AC-55/AC-56。

## 10. S10 搜索 / 最近查看

- **入口**：首页顶部搜索；「最近查看」入口在首页/列表（FR-11，P1 非阻塞）。
- **元素**：搜索框；结果分「术语」「地区/玩法」「**示例（E01~E16）**」；无结果提示；「最近查看」列表。
- **搜索契约（B-02）**：搜索**只做关键词匹配（术语/地区/玩法/示例 ID 或标题）**，**不是自由录牌输入**；命中示例时进入 S7 并**选中该示例**（与 UF-03 选例契约一致）。
- **状态**：空态＝显示热门术语；**「最近查看」空态＝「暂无最近查看」**；无结果＝「没有找到，试试其它关键词」；错误态不适用；低置信命中结果标灰。
- **返回行为**：清除搜索返回来源页，保留来源页状态；点击「最近查看」项进入对应玩法/术语/示例页。
- **对应**：UF-01/UF-02｜FR-11｜AC-21（非关键）、**AC-46（最近查看，非关键）**。

## 12. 导航与返回行为契约（统一）

1. 采用单一导航栈；返回键＝栈回退，**任何二级/三级页返回不得丢失用户在上一屏的查询、选择与滚动位置**（AC-10）。
2. 「返回不丢状态」的实现口径：状态提升到共享 ViewModel/导航图作用域，切换屏幕不重建查询态；主题/语言切换同样不重建业务态（AC-16/AC-33）。
3. 深链/恢复：进程被系统回收后重建，至少恢复到最近一次稳定页（best practice，不做跨进程持久业务态承诺）。
4. 首页为根；根上返回＝退出。
5. 无 Tab 造成的一级返回依赖栈回退与首页入口，**不得**用底部栏替代（AC-01）。

## 13. 动效与可访问性边界

- **动效（B-01）**：仅使用轻量、可关闭的过渡（页面淡入/结论条展开）；**不新增长时间动画**；系统 SplashScreen 为真实系统界面，**不是**长时间插画（AC-28）；**尊重系统「减少动态效果」偏好——开启时关闭页面切换与结论条展开动画**（AC-51）。
- **可访问性（B-01/B-05）**：
  - 所有牌面图提供 alt/无障碍标签（用牌名，走语言资源）；**页面、按钮、提示、错误、空态、安全说明、通知、无障碍标签全部走资源**，中英各一份（FR-20/AC-48）。
  - 文字与背景对比度满足可读性（正文≥4.5:1、大文本/图标≥3:1）；**具体 Token 值见 `DESIGN_FREEZE_V1.0.draft.md` §2**（含浅/深双套、前景/背景配对、低置信灰态、disabled/focus/pressed 与状态文字/图标颜色）；结论四态**不单靠颜色**区分，同时用文字标签（色盲友好）（AC-55）。
  - **触控目标≥系统建议最小值；系统大字体缩放下正文不截断**（AC-51）。
  - 英文长文本/溢出可读（AC-34）。
- **边界声明**：本契约定义**可测**的交互与结构；审美/主观项见 §14。
