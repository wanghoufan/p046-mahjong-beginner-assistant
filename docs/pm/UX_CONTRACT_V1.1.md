## 7. S7 牌例判定（「为什么不能胡」）

- **入口**：S1 首页「常见问题」→「为什么不能胡」；或由 S2 对照牌面追问。**牌例只能从已审核示例列表（E01~E07、E16，共 8 例）选择**，列表项＝示例标题＋一句话预览（见 §10 示例搜索契约，B-02）。

- **四态结论呈现规则（FR-04，统一口径＋逐例例外，B-03）**：
  1. **能胡（前提成立）**：绿色结论条「按〈玩法名〉前提，满足胡牌条件」＋为什么＋前提条件逐条列出。**前提必须逐例展示**（座风/花牌/明碰等）。
  2. **不能胡**：红色/中性结论条「按〈玩法名〉，不能胡」＋为什么（如结构不成立、无有效番）。
  3. **未满足额外条件**：琥珀色结论条「结构成立，但还差…」＋差什么（13 张待补张 / 未过海南条件 / 番不足）＋**明确区分 13 张与 14 张**。

## 9. S9 设置（主题与语言）

- **入口**：右上角 `设置`（S1 及各页可达）。
- **主题设置项**：`浅色 LIGHT` / `深色 DARK` / `跟随系统 SYSTEM`；**默认 `SYSTEM`**。
- **语言设置项**：`跟随系统 FOLLOW_SYSTEM` / `简体中文` / `English`；**默认 `FOLLOW_SYSTEM`**。
- **两个开关的触发条件分开写清（B-06，硬约束）**：
  - **`SYSTEM`（主题）只随设备「外观」**（浅/深）变化：设备切深色→APP 变深色；设备切浅色→APP 变浅色。**手动 `LIGHT`/`DARK` 不随设备外观变**（用户选项优先）。
  - **`FOLLOW_SYSTEM`（语言）只随设备「语言」**（locale）变化。**手动「简体中文/English」不随设备语言变**。
  - **两者互相独立**：改设备外观**不影响**语言选择，改设备语言**不影响**主题选择；一个手动、一个跟随可并存。
  - 系统语言不受支持时**统一回退 `zh-CN`**（不空白、不回退 en）。
- **持久化与读取边界**：主题/语言选择**重启后保留**；**持久化值在首帧（含启动页）之前读取并生效**，避免闪错色/闪错语言。
- **冷启动一致性判据（B-06）**：
  - `LIGHT` + 设备深色 → 冷启动启动页用浅色底 `#F3F8F4`，首页保持 `LIGHT`（不随设备变暗）。
  - `DARK` + 设备浅色 → 冷启动启动页用深色底 `#10211C`，首页保持 `DARK`。
  - `SYSTEM` + 设备外观 → 启动页与首页**跟随设备外观**，启动页→首页**无闪错色**。
  - **验收步骤（【V1.1】浏览器/设备）**：①三组冷启动录屏（启动页→首页）；②重载后主题/语言仍为所选；③分别改设备外观/语言，验证各自独立触发。
- **切换时状态保持**：**切换主题或语言后，返回用户所在规则页，保持同一玩法、滚动位置、已选牌例、两级判定展开状态**（不重置业务状态）（AC-16/AC-33）。
- **元素**：主题三选（单选）；语言三选（单选）；关于/来源与「非博彩声明」入口。
- **状态**：
  - 空态/错误态：不适用（纯本地设置）。
  - 低置信灰态：不适用。
- **返回行为**：返回进入设置前的页面，状态保持。
- **对应**：UF-08｜FR-13~FR-22｜AC-11~AC-16/AC-29~AC-34/AC-41/AC-55/AC-56。

## 12. 导航与返回行为契约（统一）

1. 采用单一导航栈；返回键＝栈回退，**任何二级/三级页返回不得丢失用户在上一屏的查询、选择与滚动位置**（AC-10）。
2. 「返回不丢状态」的实现口径（【V1.1】Web）：状态提升到共享的页面级会话状态（如 `app.js` 的 `state`），切换屏幕不重建查询态；主题/语言切换同样不重建业务态（AC-16/AC-33）。
3. 深链/恢复：页面重载后至少恢复到首页（best practice，不做跨刷新持久业务态承诺）。
4. 首页为根；根上返回不产生空白页。
5. 无 Tab 造成的一级返回依赖栈回退与首页入口，**不得**用底部栏替代（AC-01）。

## 13. 动效与可访问性边界

- **动效（B-01）**：仅使用轻量、可关闭的过渡（页面淡入/结论条展开）；**不新增长时间动画**；启动页为 HTML 纯色淡出，**不是**长时间插画（AC-28）；**尊重系统「减少动态效果」偏好——开启时关闭页面切换与结论条展开动画**（AC-51）。
- **可访问性（B-01/B-05）**：
  - 所有牌面图提供 alt/无障碍标签（用牌名，走语言资源）；**页面、按钮、提示、错误、空态、安全说明、通知、无障碍标签全部走资源**，中英各一份（FR-20/AC-48）。
  - 文字与背景对比度满足可读性（正文≥4.5:1、大文本/图标≥3:1）；**具体 Token 值见 `DESIGN_FREEZE_V1.0.draft.md` §2**（含浅/深双套、前景/背景配对、低置信灰态、disabled/focus/pressed 与状态文字/图标颜色）；结论四态**不单靠颜色**区分，同时用文字标签（色盲友好）（AC-55）。
  - **触控目标≥系统建议最小值；系统大字体缩放下正文不截断；`viewport-fit=cover` 下用 `env(safe-area-inset-*)` 补安全区**（AC-51/AC-61）。
  - 英文长文本/溢出可读（AC-34）。
- **边界声明**：本契约定义**可测**的交互与结构；审美/主观项见 §14。
