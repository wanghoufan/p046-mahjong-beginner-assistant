# P046 麻将小白助手 · 本地离线 HTML 交互原型（Phase 1 设计验证物）

> 类型：**设计验证物**，不是 Android 业务代码，也不是 APK。
> 用途：为 Human 2（正式原型审批）与 Design Freeze 提供可点击、可离线打开的交互原型。
> 真源：`docs/pm/PRODUCT_PLAN_V1.0.md`、`docs/pm/UX_CONTRACT_V1.0.md`、`docs/pm/DESIGN_FREEZE_V1.0.draft.md`、`docs/plan/P046-V1.2/`。
> 与 `docs/pm/` 三份正文和交接包 `docs/plan/P046-V1.2/` **一致**；本目录未改动上述任何文件。

## 1. 打开方式

- **双击 `index.html`**，浏览器以 `file://` 直接打开即可，**无需服务器、无需构建、无需联网**。
- 同一目录内相对引用 `app.css` / `app.js` / `i18n.js` / `data/*.js` / `assets/`，全部本地。
- 首次打开显示约 1.2 秒的**原型模拟启动画面**，随后进入首页。

### 为什么同时有 `*.json` 与 `*.js` 镜像（改数据必须同步两处）

`file://` 下浏览器的 `fetch()`/`XMLHttpRequest` 对本地文件会被 CORS 拦截，无法直接读取 JSON。为满足「双击即用、零 fetch/XHR」的硬约束，运行期数据以 `data/*.js` 形式通过 `<script>` 加载；`data/*.json` 作为可供 QA/开发直接查看的规范记录源。

**双份维护规则（本轮已落警示注释，两个文件头部各一处）**：

- **`data/*.js` 是运行期真源**（页面真正吃进去的那份），**`data/*.json` 是规范记录源**（给 QA/开发看、做一致性比对的那份）。
- **改数据必须同步两处**：任何一边改动都要在另一边写入同样内容，改完必须保持两份**逐字节 JSON 等价**，否则会出现「QA 看 json 对、线上跑 js 错」。
- JSON 不支持注释，故警示以首键 `"_sync_warning"` 形式写在两份 JSON 对象头部；`.js` 侧则同时有文件头注释与同一个首键。**本轮不引入构建脚本或本地服务器**（`file://` 取舍维持不变）。

## 4. 哪些是「原型模拟」而非真机能力（不美化）

- **启动画面**：为 HTML 模拟；真机为 Android 系统 SplashScreen API。
- **`SYSTEM` 跟随外观**：原型用浏览器 `prefers-color-scheme` 模拟；真机由 Android 外观配置驱动（设置页已标注）。
- **`FOLLOW_SYSTEM` 回退 zh-CN**：原型用 `navigator.language` 模拟；真机由系统语言列表驱动（设置页已标注）。
- **设置持久化**：原型用 `localStorage` 模拟；真机为原生偏好存储。
- **判例判定**：**静态已审核示例渲染，不是判牌引擎**；无手工录牌、无任意牌张输入、无拍照/动态判牌。
- **规则内容**：仅呈现已审核静态内容；未核实项（「当花又当眼」）保持低置信灰态，不出确定性胡牌结论。

## 8. 关键文案（三个问题页实际渲染文本，服务 AC-53）

- **E01**｜结论：**还差一张，现在胡不了**　标题：`13张等待另一张二条`
  - 为什么：`手里 13 张：四组三张都齐了，末尾只有一张二条，还差一张凑成对子（两张一样才叫对子，那一对就是眼）。所以这会儿胡不了，摸到另一张二条才成。`
- **E03**｜结论：**末尾凑不出对子，胡不了**　标题：`14张末尾无对子`
  - 为什么：`末尾是二条和五条，两张不一样，凑不成对子；整手也找不出别的摆法能凑成「四组＋一对」。已经是 14 张了，不能说「再摸一张就胡」，只能打掉一张重新摆。`
- **E04**｜结论：**这手牌能胡**　标题：`二条做眼，提供一种番`
  - 为什么：`这对二条是眼，而且牌面是二、五、八之一，正对上条件一，所以它给一种番。有了番，别人打出来的牌也能胡（点炮胡）；具体到你们那桌，以上桌问一句为准。`
- **E07**｜结论：**花没对上座位，手上也没别的番，胡不了**　标题：`非对应座位花牌，不自动算番`
  - 为什么：`春花要配东位才算（这套资料里，东位拿春花才给番）。你坐南位，对不上，所以这张花不给番。手上又没有别的番，就不能说「别人打出来我能胡」。你们那桌要是不一样，上桌先问一句。`

## 10. PWA：本地服务与部署

- **`file://` 双击打开**：内容、双语、深色、牌图全部正常；但浏览器**不允许 `file://` 注册 Service Worker**，故「离线缓存 / 安装到桌面 / 自动更新」在双击方式下不生效（`app.js` 已加协议守卫，仅 `http(s)` 注册，`file://` 不会报错）。
- **本地服务（推荐，验证完整 PWA 能力）**：

  ```bash
  # 在 prototype/ 目录下（或其父目录）执行，任选其一
  python3 -m http.server 8080          # 本机访问 http://localhost:8080/
  python3 -m http.server 8080 --directory prototype
  ```

  打开 `http://localhost:8080/`（若在父目录起服务则为 `/prototype/`）即可看到完整效果：安装到桌面、断网可用、新版本自动更新。
- **Service Worker**：入口 `prototype/sw.js`，顶行 `SW_VERSION` 常量控制缓存版本（如 `"p046-v1"`）。发新版本时改这个值，旧缓存会在 `activate` 时清理，页面加载后弹出「发现新版本，已自动更新。」。
- **部署**：本目录为纯静态站点，**必须经 HTTPS（或 localhost）** 才能启用 SW。把 `prototype/` 全量上传到任意静态托管（GitHub Pages / Netlify / Vercel / 对象存储 + CDN）即可；`start_url`/`scope` 均为相对路径 `./`，放在子目录也能工作。
- **图标**：`assets/brand/icon-192.png`、`icon-512.png`（512 带 `purpose: "any maskable"`）、`apple-touch-icon.png`、`favicon.png` 均由 `play-store-512.png` 派生，尺寸已逐个校验。
